stickify

The sidebar on this page, running

Full option-parity port of Theia Sticky Sidebar — collapsible margins, floated multi-column layouts, and responsive stacking, handled the same way the original does. That sidebar to the left has been stickify'd since you loaded this page; scroll and watch it clamp to its container instead of overflowing the footer.

menuify

Flat list in, nested dropdown out

Turns a flat <ul><li><a> link list into a nested dropdown — any link whose text starts with the nesting prefix (_ by default) gets nested under the previous non-prefixed link, and the prefix is stripped. The fixed header above runs menuify("#menu") too, for its keyboard/touch handling, on top of hand-built markup; the box below is the plain, un-styled result straight out of the plugin — edit nothing, just call menuify().

lazify

Images load only when near view

lazify("img[data-src]") swaps data-src into src as each image nears the viewport — no library beyond blogr-plugins required. Scroll down to watch the log below fill in.

Lazify Demo

tocify

The sidebar's "On this page" list, running

Builds a nested table-of-contents from the headings inside a container, assigning ids to any heading that doesn't already have one. The On this page list in the sidebar was generated this way — from every h2 on this exact page, including this one.

shortcodify

Bracket tags, rewritten to HTML

shortcodify("#shortcode-demo", { tags: defaultShortcodeTags }) turns [b]…[/b]-style markup into real elements. Unregistered tags — like [mystery] below — are left as-is by default.

Say [b]hello[/b] to [color name="crimson"]resize-image[/color], now with a [url href="https://github.com"]link[/url] and an unknown [mystery]tag[/mystery].

replacify

Find-and-replace, text nodes only

Walks text nodes and swaps matches in place — tags and attributes are never touched, so it's safe to run on rendered markup. The eyebrow label at the very top of this page (blogr-plugins → blogr-plugins™) was rewritten this way when the page loaded.

cookify

Tiny cookie get/set helper

cookify.set("theme", "dark", { expiresDays: 30 }) and cookify.get("theme") — plain reads and writes, no parsing boilerplate. Every call on this page, including the resize/lazy-load/shortcode demos above, is logged live below.

createWidget

Related posts, in the sidebar, running

A self-contained Blogger listing widget — related posts, recent posts, random picks, comments, or pages — built on the blogr SDK. It mounts into a container, defers its own fetch until that container nears the viewport, resizes thumbnails via resizeImage, and can page results with infinite scroll and/or a load-more button. The Related posts box in the sidebar is one of these, live.

Reference

Every plugin, at a glance

Full parameter-by-parameter documentation — every option, every lifecycle hook, every internal helper — lives in README.md (and createWidget.MD for that one). This is the quick-scan version.

Function Description
stickify(target, options?) Sticks a sidebar to the viewport while scrolling, clamped to its container. Full option-parity port of Theia Sticky Sidebar.
menuify(target, options?) Turns a flat <ul><li><a> list into a nested dropdown via a nestingPrefix.
lazify(target, options?) Lazy-loads <img>, <iframe>, <video> and background images via IntersectionObserver.
tocify(target, options?) Builds a nested table of contents from the headings inside a container.
replacify(target, search, replacement, options?) Find-and-replace inside text nodes only — never touches tags or attributes.
shortcodify(target, options) / renderShortcodes(text, options) A full [tag attr="value"]content[/tag] shortcode engine — nesting, self-closing tags, a reusable tag registry.
cookify.set / get / getAll / remove Dependency-free cookie utility. Values are JSON-encoded automatically.
resizeImage(url, options?) Rewrites a Blogger image or YouTube thumbnail URL; returns unsupported URLs unchanged.
isSupportedImage(url) Checks whether a URL is a recognized Blogger image or YouTube thumbnail, without rewriting it.
installResizeImagePrototypes() Adds .resizeImage() to String, Array, Element and NodeList prototypes. Idempotent.
createWidget(options) Self-contained related/recent/random-posts, comments, or pages widget built on the blogr SDK. Returns { destroy, refresh, setQuery }.

See README.md for the full reference, including every option table, and createWidget.MD for createWidget's complete prop list, lifecycle hooks, and recipes.
